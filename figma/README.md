# Импорт главной страницы МПА СНГ в Figma

Откройте [index.html](index.html) через локальный HTTP-сервер и импортируйте страницу с помощью расширения [html.to.design](https://html.to.design/docs/what-is-the-browser-extension/). HTML содержит стили Tailwind, изображения и шрифт Golos Text. Для просмотра макета интернет не нужен.

1. Из корня репозитория запустите **python3 -m http.server 8000 --bind 127.0.0.1** и откройте [страницу в Chrome](http://127.0.0.1:8000/figma/).
2. Для десктопного макета задайте ширину окна 1440 px. Для мобильного макета включите режим адаптивного просмотра в Chrome DevTools и задайте ширину 390 px.
3. В расширении html.to.design захватите всю страницу. Можно отправить захват прямо в плагин Figma или сохранить файл .h2d и открыть его через вкладку File плагина. Повторите захват для второй ширины. [Инструкция по импорту .h2d](https://html.to.design/docs/open-h2d-file/)

В макете зафиксированы первые слайды обеих каруселей и время на 12:00 по Москве. Меню и поиск показаны закрытыми. Для интерактивной версии используйте index.html в корне репозитория.

После изменений основной страницы пересоберите макет командами **npm ci** и **npm run build:figma**. Лицензия шрифта находится в [Golos-Text-OFL.txt](Golos-Text-OFL.txt).
